Truth before theatre

Designed for the awkward moments too.

Timeouts, partial usage, cancellation and stale external state are treated as visible operating conditions, not rounded away as success.

  • Single-shot Ghost writesAmbiguous responses reconcile before another publish attempt.
  • Dry-run isolationSimulation does not mutate the queue, duplicate index or Ghost.
  • Soft budgets stay softWarnings remain visible without silently stopping automation.
  • Verified state backupsChecksums and SQLite integrity are checked before download.

Questions operators ask

Know the operating model before the first run.

Does a dry run publish anything?

No. It records the run, timeline, metered usage and simulated evidence while leaving Ghost and durable content state unchanged.

Can it publish directly?

Yes, when Ghost is configured for a live status and the operator acknowledges that destination for the specific run. Draft remains the safer default.

How is AI cost calculated?

Known cost comes from actual response tokens multiplied by the event-time model catalog. Missing usage or unknown pricing is shown as incomplete.

Does it replace Ghost?

No. Ghost remains the editor and publishing authority. The application controls automation, monitoring, reconciliation and static delivery.

What happens after a publish timeout?

The write is marked uncertain and checked through a read-only Ghost reconciliation before another publish can be attempted.
